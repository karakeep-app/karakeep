Read-only code examples

This article contains two code examples embedded in read-only editor widgets. Saving the article should preserve their complete copy payloads, including indentation, blank lines, and characters that look like HTML. The first example keeps its original textarea while the second renders only a visible line of an editor after the page loads.

The directory listing above uses spaces for the file name, an empty line, and a tab for the final command. These characters are part of the example and should survive extraction without being replaced by the editor's loading placeholder or converted into a single line of prose.

The rendered example contains literal HTML inside a JavaScript string. Its full copy payload includes a second statement separated by a blank line, even though the visible editor only contains a placeholder line. Both statements belong in the saved article as literal code.
