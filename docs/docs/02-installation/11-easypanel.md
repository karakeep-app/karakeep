# Easypanel

[Easypanel](https://easypanel.io) is a self-hosted Docker deployment platform. It maintains a one-click deployment template for Karakeep that wires up the web app, Meilisearch, and a headless Chrome instance for you automatically.

[![Deploy on Easypanel](https://easypanel.io/img/deploy-on-easypanel-40.svg)](https://easypanel.io/templates/karakeep)

### Get started

1. Visit the [Karakeep template page](https://easypanel.io/templates/karakeep) and click Deploy.
2. Optionally set an OpenAI API key in the template form for AI-based tagging.
3. Once deployed, visit the assigned domain and create your first user under Sign Up.
