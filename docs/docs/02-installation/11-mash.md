# MASH (Ansible)

:::info
The MASH playbook is maintained by the community.
:::

Karakeep can be installed with [MASH](https://github.com/mother-of-all-self-hosting/mash-playbook), an Ansible playbook that deploys self-hosted services as Docker containers. See its [Karakeep documentation](https://github.com/mother-of-all-self-hosting/mash-playbook/blob/main/docs/services/karakeep.md) for the configuration to add to your `vars.yml` file.
