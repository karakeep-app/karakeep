Theming shadcn/ui entirely through CSS variables
AI TITLE original: “Theming — shadcn/ui”
SUMMARY
Every colour in the library resolves through a small set of semantic tokens declared on the root element, so a single override cascades to every component without forking source. The page maps each token to its role — surface, muted, accent, border — and shows a warm-neutral remap as a worked example, including the dark-mode pairs.
KEY POINTS
—Tokens are HSL triples, not colour functions, so they compose in hsl(var(--x) / 0.5).
—Dark mode is a second block on .dark, not a separate theme file.
—Border and ring share one token — changing it retunes every focus state at once.
