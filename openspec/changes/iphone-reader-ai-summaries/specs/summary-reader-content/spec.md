# Spec Delta

## Purpose

Показывать готовый конспект основным содержимым режима чтения в существующем мобильном клиенте, не уничтожая оригинал и сохраняя совместимость контракта API.

## ADDED Requirements

### Requirement: Саммари как основной текст
При включённой серверной настройке система SHALL выдавать готовое саммари актуального источника вместо статьи в HTML-содержимом режима чтения без обязательного обновления приложения.

#### Scenario: Чтение готового результата
- **WHEN** мобильный reader запрашивает содержимое закладки с готовым саммари
- **THEN** основной текст содержит заголовки, абзацы и списки саммари, а не только отдельный блок AI Summary.

#### Scenario: YouTube без читаемой страницы
- **WHEN** саммари видео готово, но исходная страница не признана пригодной для чтения
- **THEN** серверная выдача позволяет открыть саммари в режиме чтения, сохраняя доступ к видео.

### Requirement: Оригинал до готовности
Система SHALL отдавать исходное содержимое, если режим отключён или актуальное саммари отсутствует, ожидает генерации либо генерация завершилась ошибкой.

#### Scenario: Саммари ещё готовится
- **WHEN** клиент запрашивает статью до завершения обработки
- **THEN** сервер возвращает оригинальный материал без пустой подмены.

#### Scenario: Источник изменился
- **WHEN** сохранённое саммари относится к предыдущей версии источника
- **THEN** reader получает оригинал до готовности нового результата.

### Requirement: Сохранение оригинала
Система MUST хранить оригинал отдельно от представления для чтения и сохранять его доступным для обработки, экспорта и открытия исходного URL.

#### Scenario: Повторная генерация
- **WHEN** создаётся новое саммари
- **THEN** генератор получает исходный текст, а не HTML предыдущего саммари.

#### Scenario: Открытие сайта
- **WHEN** пользователь открывает исходную ссылку в браузере
- **THEN** открывается первоначальная статья или видео.

### Requirement: Безопасное форматирование
Система MUST преобразовывать Markdown в безопасный HTML без исполняемых скриптов, обработчиков событий и опасных URL, явно обозначая содержимое как ИИ-саммари.

#### Scenario: Опасная разметка в ответе
- **WHEN** ответ генератора содержит скрипт или ссылку с опасной схемой
- **THEN** выдаваемый HTML удаляет опасное содержимое и сохраняет допустимое форматирование.

### Requirement: Совместимость и кеширование
Решение SHALL сохранять существующую схему API и пройти проверку на установленном приложении App Store: повторное получение содержимого показывает готовое саммари, а обновлённая офлайн-копия сохраняет его форматирование.

#### Scenario: Переход от оригинала к саммари
- **WHEN** до генерации читался оригинал, а затем клиент повторно получает содержимое после готовности
- **THEN** он отображает саммари; необходимые действия обновления фиксируются для проверенной версии приложения.

#### Scenario: Чтение офлайн
- **WHEN** пользователь обновил офлайн-копию после готовности саммари и отключил сеть
- **THEN** приложение показывает сохранённое саммари с форматированием.

#### Scenario: Старая офлайн-копия
- **WHEN** клиент офлайн и сохранил оригинал до генерации
- **THEN** сохранённый оригинал остаётся читаемым; мгновенная серверная замена офлайн-копии не требуется.
